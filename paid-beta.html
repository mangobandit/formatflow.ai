Before you buy

Clear limits, with no surprise provider bill.

Windows beta

The current public build is a Windows beta. The installer is not yet code-signed, so Windows can display an unknown-publisher warning. Verify the published checksum before installing.

Bring your own AI provider

The FormatFlow license does not include OpenAI, Anthropic, Gemini or other provider usage. Those providers may charge you separately. Ollama can be used for local model workflows.

Review is still required

Machine translation and layout checks can be wrong. Review translated files before legal, safety-critical, financial, medical or client delivery use.
