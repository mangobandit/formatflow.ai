Questions before you install.

Do my files leave my computer?
Studio opens and rebuilds original files locally. In the current beta, text and translation context go directly to your selected provider under your API key. The planned business package will route that text through the FormatFlow backend to OpenAI. See the privacy policy for the separate browser preview flow.
Which formats can I translate?
Studio supports PowerPoint (.pptx), Word (.docx) and Excel (.xlsx). Text-based PDF import is beta and exports translated Word (.docx), without preserving the PDF layout. Scanned PDFs and image text have no OCR support. Legacy Office formats, CSV, plain text and OpenDocument files are not supported document inputs. The browser tester analyses PPTX, DOCX and PDF only.
How does the two-day trial work?
Install the Windows app and activate the included two-day trial to test the full workflow with your own documents. Your AI provider may charge separately for model usage under your own API key.
Will my team need an OpenAI API key?
The planned business package will include OpenAI access managed and paid for by FormatFlow, with an agreed usage allowance. Customers will activate a seat instead of entering an OpenAI credential. The current public beta still requires a customer-supplied provider key for cloud translation.
Is InDesign included?
The initial business package will focus on FormatFlow Studio. FormatFlow Translate for InDesign is a separate development preview, with an optional business add-on planned later. Its preview still needs validation inside Adobe InDesign before client work.
Why might Windows show a warning?
The current installer has not yet been code-signed, so Windows may display an unknown-publisher warning. Download only from formatflow.ai and compare the file’s SHA-256 value with the published checksum.
What happens after the trial?
Contact us to discuss the planned annual business package. The proposal will specify named seats, the annual price and included AI usage. Business activation and security validation are still pending; the current beta has separate terms and is not the managed business release.
