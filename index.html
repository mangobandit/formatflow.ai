Questions before you install.

Do my files leave my computer?
No. FormatFlow Studio reads, processes and saves files on your Windows machine. Translation connects directly to the AI provider you select using your own API key; your documents do not pass through FormatFlow’s servers.
Which formats can I translate?
FormatFlow Studio translates PowerPoint (.pptx) and Word (.docx) files today. The browser tester can also analyse PDFs and prepare a QA report, while layout-preserving PDF translation remains on the roadmap.
How does the two-day trial work?
Install the Windows app and activate the included two-day trial to test the full workflow with your own documents. Your AI provider may charge separately for model usage under your own API key.
Why might Windows show a warning?
The current installer has not yet been code-signed, so Windows may display an unknown-publisher warning. Download only from formatflow.ai and compare the file’s SHA-256 value with the published checksum.
What happens after the trial?
If FormatFlow fits your workflow, request a written paid-beta quote. You receive the price, license duration, tax details and terms before paying; there is no automated card checkout on this site.
