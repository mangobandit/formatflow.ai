Translate Office files. Keep their structure.

FormatFlow Studio brings Word, PowerPoint and Excel translation into a simple Windows workflow: drag in files, choose languages, translate, then review and export. Text-based PDF import is available in beta and produces a Word document.

Supported file formats.

Studio input and translated output
InputOutputWhat to expect
PowerPoint (.pptx).pptxSupported slide and speaker-note text, with Office structure retained.
Word (.docx).docxSupported document text, including tables, headers and footers.
Excel (.xlsx).xlsxSupported workbook text; formulas and numeric values are retained.
Text-based PDF (.pdf) — beta.docxExtractable text becomes a translated Word document. Original PDF layout is not preserved.

Scanned PDFs and images need OCR, which Studio does not provide. Legacy .doc, .ppt and .xls files, CSV, plain text, OpenDocument and InDesign files are not supported Studio inputs. Embedded image text and some chart or SmartArt content may need manual work. Test representative files before adopting the workflow.
