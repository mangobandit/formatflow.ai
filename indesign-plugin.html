Adobe InDesign UXP plugin · Version 1.2.1

Translate inside InDesign with GPT-5.6.

Run multi-language document translation from an InDesign panel while keeping the original file untouched. Version 1.2.1 adds GPT-5.6 Sol, Terra and Luna and fixes the paragraph-range issue that could clip the opening words of translated text blocks.

Download version 1.2.1 Read the privacy policy

What changed in 1.2.1.

Safer text writes

Every paragraph is re-resolved immediately before it is changed, preventing stale InDesign text ranges from clipping leading words.

GPT-5.6 model tiers

Choose Sol for highest quality, Terra for balance or Luna for the fastest workflow.

File-first workflow

The plugin creates and translates a separate language copy. Your open source document is not edited.

Install and run.

1. Unzip

Extract the downloaded package to a permanent folder on your computer.

2. Load in UXP Developer Tool

Add the plugin by choosing its manifest.json, then load it into Adobe InDesign 18.5 or newer.

3. Translate a copy

Open the panel, choose your output folder and languages, enter your own provider key, and start with one short test document.

Verify the plugin package.

The download is 43,253 bytes. API keys are not included in the ZIP; you enter your own key locally in the plugin.
