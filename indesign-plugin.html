Adobe InDesign UXP plugin · Version 3.1.0

Translate inside InDesign with GPT-5.6.

The complete FormatFlow Translate interface is back: IDML-safe multi-language translation, the working Overset Text Fixer, preflight and batch export, all while keeping the original file untouched. Version 3.1.0 also adds GPT-5.6 Sol, Terra and Luna and retains the fix for clipped opening words.

What is restored in 3.1.0.

Overset Text Fixer

Scan any active document, then fit overset text through the least-invasive ladder: tracking, leading and point size, within limits you control.

Automatic copy fitting

The same overset solver runs after each translated document is rebuilt, with anything still requiring manual layout clearly flagged.

Full themed interface

Use the complete tabbed panel with Auto, Dark and Light themes, Quick Translate, Preflight, Batch Export, Help and Settings.

Safer text writes

Every paragraph is re-resolved immediately before it is changed, preventing stale InDesign text ranges from clipping leading words.

GPT-5.6 model tiers

Choose Sol for highest quality, Terra for balance or Luna for the fastest workflow.

48 languages at once

A three-state check/uncheck all control complements the regional presets, so large batches take one click to configure.

Install and run.

1. Unzip

Extract the downloaded package to a permanent folder on your computer.

2. Load in UXP Developer Tool

Add the plugin by choosing its manifest.json, then load it into Adobe InDesign 18.5 or newer.

3. Translate a copy

Open the panel, choose your output folder and languages, enter your own provider key, and start with one short test document.

Verify the plugin package.

The download is 167,184 bytes. API keys are not included in the ZIP; you enter your own key locally and the plugin remembers it per provider when requested.
