Adobe InDesign UXP plugin · Version 3.3.0 development preview

New AI tools. Your InDesign workflow.

Translate copies of your documents with updated OpenAI, Claude and Gemini presets, DeepL or local Ollama. Keep the full themed interface, Overset Text Fixer, preflight and batch export, with stronger checks for missing text, links and protected terms.

Automated checks use simulated provider responses. This preview still needs testing inside Adobe InDesign before client work; start with a copy of a short, representative document.

What is new in 3.3.0.

Overset Text Fixer

Scan any active document, then fit overset text through the least-invasive ladder: tracking, leading and point size, within limits you control.

Automatic copy fitting

The same overset solver runs after each translated document is rebuilt, with anything still requiring manual layout clearly flagged.

Full themed interface

Use the complete tabbed panel with Auto, Dark and Light themes, Quick Translate, Preflight, Batch Export, Help and Settings.

Stronger text protection

Missing or duplicated translation IDs and protected tokens are rejected. Incomplete text is repaired or the batch reports an error before saving that output.

Current providers and custom models

Choose an updated AI preset or enter an exact model ID available on your account. Your chosen model is remembered without silently switching you to another tier.

Safer cancellation and Private mode

Cancel stops new work and prevents a cancelled DeepL job from saving files. Private mode blocks cloud translation and cloud key tests. The check/uncheck all control still covers all 48 languages.

Install and run.

1. Unzip

Extract the downloaded package to a permanent folder on your computer.

2. Load in UXP Developer Tool

Add the plugin by choosing its manifest.json, then load it into Adobe InDesign 18.5 or newer.

3. Test a document copy

Choose your output folder and languages, enter your own provider key, and test one short document. Check styles, hyperlinks, overset, right-to-left text and PDF output before a larger batch. A request already in progress may finish before cancellation takes effect.

Verify the plugin package.

API keys are not included in the ZIP. Enter your own key in the plugin; cloud providers receive the text needed for translation under your account. Use Private mode with local Ollama for on-device processing.
